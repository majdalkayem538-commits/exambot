# بوت الاختبارات — كلية الاقتصاد

## التشغيل
`python main.py` — كل الإعدادات من الـ Environment:

| المتغير | مطلوب؟ | شو هو |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت |
| `SUBJECT_1_ADMIN_ID` | ✅ | ID الآنسة سمارا |
| `SUBJECT_2_ADMIN_ID` | ✅ | ID الآنسة زينب |
| `DB_PATH` | على Render ✅ | `/var/data/exam_bot.db` |
| `OWNER_ID` | مُستحسن | ID صاحب البوت: نسخة احتياطية يومية + إحصائيات كل المواد |
| `MIN_SOLVE_MINUTES` | اختياري | أقل وقت قبل زر «لقد أنهيت الحل» (افتراضي 0) |
| `BACKUP_HOUR` | اختياري | ساعة النسخة اليومية (افتراضي 3 الفجر) |
| `WATERMARK` | اختياري | 1 = علامة مائية باسم الطالب على الحلول (افتراضي)، 0 = بدون |
